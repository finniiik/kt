# Beauty Café — учебный статический лендинг

## Секции
Header → Hero → Features (три карточки нот) → блок покупки → Footer.

## Дизайн
Журнальная типографика, крупное название продукта, настоящее фото флакона, розовые акценты и свободное пространство. Заголовки: Cormorant Garamond; основной текст: Manrope. Цвета определены семантическими OKLCH-токенами в глобальных стилях. Секции используют CSS-модуль.

Среда Lovable использует TanStack Start, а не Next.js App Router. Проект не выполняет требование Next.js. Экспорт через GitHub API не подключает двухстороннюю синхронизацию Lovable.
